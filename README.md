## 🏗️ Full Pipeline

```
User Query
  │
  ├─[1] DistilRoBERTa   → emotion, distress level, empathy mode   [LOCAL, FREE]
  │
  ├─[2] all-MiniLM-L6-v2 → top 2 statutes (IPC/Acts, 150 chars)  [LOCAL, FREE]
  │
  ├─[3] all-MiniLM-L6-v2 → top 5 similar NyayaRAG cases          [LOCAL, FREE]
  │
  ├─[4] Compact prompt builder (~180 tokens system prompt)        [LOCAL, FREE]
  │
  ├─[5] Gemini 2.0 Flash → 180-token structured answer            [API]
  │       Format: Issue | Relevant Law | Your Rights | Next Step
  │       Fallback: local RAG answer if Gemini unavailable
  │
  └─[6] UI renders: reply + sources + similar cases + confidence
```

## 📁 Project Structure

```
lexai/
├── server.js                    ← Gemini proxy (port 3001), 180 token cap
├── .env                         ← GEMINI_API_KEY=...
├── scripts/
│   ├── loadNyayaRAG.js          ← Download + merge NyayaRAG dataset
│   └── evaluateRAG.js           ← P@5, R@5, MRR, NDCG evaluation
└── src/
    ├── App.js                   ← Root router, preloads all models
    ├── rag/
    │   ├── legalDataset.json    ← 28 base statutes (IPC, Constitution, Acts)
    │   ├── mergedLegalDB.json   ← Generated by loadNyayaRAG.js (statutes + cases)
    │   ├── embeddingService.js  ← all-MiniLM-L6-v2 local embeddings
    │   ├── vectorStore.js       ← In-memory cosine similarity search
    │   ├── legalRetriever.js    ← retrieve() statutes + retrieveCases() cases
    │   └── ragEngine.js         ← Full pipeline orchestrator
    ├── utils/
    │   ├── constants.js         ← GEMINI_MODEL, MAX_TOKENS=180, MAX_HISTORY=2
    │   ├── aiHelpers.js         ← callGemini(), detect category, prediction
    │   ├── emotionAnalyzer.js   ← DistilRoBERTa local inference
    │   ├── empathyProfiles.js   ← 8 empathy modes
    │   └── requestManager.js    ← Singleton lock, LRU cache, cooldown
    ├── hooks/
    │   ├── useAuth.js           ← Login/signup context
    │   └── useChat.js           ← Full pipeline + local RAG fallback
    └── components/
        ├── shared/              ← Sidebar, GlassCard, EmotionalStatusCard,
        │                          SourcesPanel, SimilarCasesPanel, ...
        ├── chat/ChatPage.js     ← Main chat with sources + similar cases
        ├── cases/CasesPage.js   ← Semantic case similarity search
        ├── prediction/          ← Judgement prediction + XAI
        ├── emotion/             ← Emotion analytics dashboard
        ├── documents/           ← Legal document upload + AI analysis
        └── admin/               ← AdminPage, EscalationPage
```
